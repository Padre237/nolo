# Mandat — Vérificateur d'agrément (simulé)

| Élément | Contenu |
|---|---|
| Rôle | Vérifier qu'un établissement inscrit est autorisé à exercer avant qu'il soit visible des citoyens (D-029a : le format du NIU ne suffit pas) |
| Informations reçues | La fiche de l'établissement, la référence de l'autorisation d'ouverture et, pour une officine, le numéro d'inscription à l'Ordre ; ces deux références ne sont jamais publiées |
| Décisions possibles | Valider ; refuser avec un motif obligatoire ; suspendre ; un changement de NIU, de type ou de position de plus de 500 m relance la vérification |
| Textes | Loi 90/035, réservation de la pharmacie aux pharmaciens (`CMR-LOI-90-035::0012`) et interdiction de la vente hors officine (`CMR-LOI-90-035::0049`) |
| Lacunes | L9 (pas de registre ouvert des pharmacies agréées) : la liste d'agrément est simulée (`donnees/agrement_simule.json`) |
| Statut | Simulé ; le registre officiel et l'autorité de vérification restent à désigner [à valider] |
