# Mandat — District / SIMR (simulé)

| Élément | Contenu |
|---|---|
| Rôle | Investiguer un signal de surveillance au niveau du district de santé, dans le circuit officiel de la surveillance à base communautaire (SBC) et de la SIMR |
| Informations reçues | Agrégats seulement : aire de santé, syndrome, semaine, nombre de cas publié (arrondi à 5, masqué sous le seuil de 5) ; jamais de liste nominative ni de position individuelle |
| Décisions possibles | Demander une information complémentaire ; proposer une investigation ; contacter les personnes **par le circuit humain existant** (agent de santé communautaire), hors de Nolo |
| Ce qu'il ne peut pas obtenir | Une liste nominative ou des positions précises : Conformité bloque `surveillance.transmettre_donnees_individuelles` avec repli « agrégat » (FR-1923) |
| Textes | Guide SBC 2023, fonctions de la SBC (`CMR-MINSANTE-GUIDE-SBC-2023::0018`) ; loi 2024/017 art. 9, consentement (`CMR-LOI-2024-017::0011`) ; RSI art. 45, traitement des données personnelles (`INT-OMS-RSI-2005-AMENDE-2022::0054`) |
| Lacunes | L4 (pas de cadre de partage application → SIMR), L6 (guide SBC sans canal numérique) |
| Statut | Simulé ; mandat à confirmer par le MINSANTE avant tout usage réel [à valider] |
